Data & Storage Control

Flush Redis server cache, clear device & app storage, force database re-sync, or perform bulk song catalog operations.

⚡ Flush Redis Server Cache

Completely flushes all active keys across Redis cache instances (including song feeds, artist graphs, albums, and search indexes). Forces the backend to pull fresh data on the next request.

🗑️ Clear App & Local Storage

Clears client-side localStorage, sessionStorage, active upload queues, and resets cached state so all frontend screens immediately re-render clean.

🔄 Force Database Direct Re-Sync

Bypasses all cache wrappers with nocache=1, queries PostgreSQL directly, and re-populates the studio catalog and mobile feeds in real-time.

⚠️ Full Song Delete (All-in-One Wipe)

Permanently deletes ALL songs, albums, playlists, and listening history from the PostgreSQL database, purges Redis cache, and cleans Google Drive storage records.
